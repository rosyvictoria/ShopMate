Project Overview

ShopMate helps users find products based on their preferred category and budget. The application filters available products and displays matching recommendations through a Java Swing graphical interface.
ShopMate

ShopMate is a Java Swing desktop application that recommends products based on category and budget.

Features

* Product recommendation by category
* Budget-based filtering
* User-friendly GUI using Java Swing
* Error handling for invalid input

Technologies Used

* Java
* Java Swing
* ArrayList
* Git & GitHub

How to Run

1. Open the project in IntelliJ IDEA.
2. Run `Main.java`.
3. Select a category.
4. Enter your budget.
5. Click **Recommend**.
